# Perfume E-Commerce Platform 🌟

A fully-featured, responsive e-commerce web application designed for browsing, managing, and purchasing premium fragrances. 

## Live Demo
**[View Live Deployment on Vercel]([https://your-project-link.vercel.app](https://perfume-gilt-iota.vercel.app/))**

## Features
* **Dynamic Product Catalog:** Browse a comprehensive collection of perfumes with detailed descriptions, imagery, and pricing.
* **Shopping Cart & Checkout:** Seamless cart management and streamlined checkout flow for users.
* **User Authentication:** Secure user sign-up, login, and session management.
* **Responsive UI:** Optimized layout for seamless navigation across desktop, tablet, and mobile devices.
* **Real-time Inventory:** Dynamic product and order management powered by a cloud database.

## Tech Stack
* **Deployment & Hosting:** Vercel
* **Backend & Database:** Supabase
* **Version Control:** GitHub

## 💻 Local Setup & Installation

LOCAL SETUP & INSTALLATION

    Clone the repository:
    git clone https://github.com/yourusername/perfume-ecommerce.git
    cd perfume-ecommerce

    Install dependencies:
    npm install

    Configure Environment Variables:
    Create a .env.local file in the root directory and add your Supabase credentials:
    NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

    Run the development server:
    npm run dev

    Open your browser:
    Navigate to http://localhost:3000 to view the application locally.
